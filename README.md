## 1. 로컬 실행 및 빌드

```bash
npm install
npm run dev
# 프로덕션 빌드 검증
npm run build
```

## 2. 데스크톱(Mac) & 갤럭시(Android) 동시 사용법

1. **Vercel 무료 배포**: 이 폴더를 GitHub에 올린 뒤 Vercel에 연결하면 전용 URL이 생성됩니다.
2. **갤럭시 안드로이드 앱 설치**: 갤럭시 Chrome 또는 삼성 인터넷에서 배포 URL 접속 → 우측 상단 메뉴 `홈 화면에 추가(앱 설치)`를 누르면 네이티브 앱처럼 단독 창으로 실행됩니다.
3. **맥 데스크톱 앱 설치**: Chrome/Edge 주소창 우측의 `앱 설치` 아이콘을 누르면 Dock에 독립 앱으로 등록됩니다.
4. **Supabase 실시간 동기화**: 앱 내 우측 상단/좌측 하단의 `동기화 · 백업 설정` 버튼을 눌러 SQL을 1회 실행하고 Supabase URL과 Anon Key를 입력하면 데스크톱과 갤럭시에서 동시에 동기화됩니다.
